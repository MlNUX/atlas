# Tastenkürzel

## Allgemein

| Kürzel | Aktion |
|---|---|
| Strg+P | Arbeitsleiste: Dateien, Ordner, Notizen, Aktionen (`>` Aktionen, `#` Tags, `@` Zitate und PDF-Anmerkungen, `!` Termine, `:` Zeile, `?` Volltext, `pfad:42`) |
| Strg+Umschalt+P | Arbeitsleiste mit Aktionen |
| Strg+O | Projektordner öffnen |
| Strg+Umschalt+F | Projektweite Suche |
| Strg+Umschalt+E | Explorer |
| Strg+B | Seitenleiste ein-/ausblenden |
| Strg+` | Terminal-Panel ein-/ausblenden |
| Strg+Umschalt+` | Neues Terminal |

Strg+P und Strg+` funktionieren auch, wenn ein Terminal den Fokus hat;
alle übrigen Tasten gehen dort an das Programm im Terminal.

## Tabs und Splits

| Kürzel | Aktion |
|---|---|
| Strg+\\ | Editor teilen |
| Strg+W | Tab schließen |
| Strg+Tab / Strg+Umschalt+Tab | Nächster / vorheriger Tab |
| Alt+← / Alt+→ | Zurück / vor (Ordner, gefolgte Links) |
| Strg+Klick, Mittelklick | In neuem Split öffnen |
| Doppelklick | Vorschau-Tab fest anheften |
| Tab ziehen | Im Tab-Streifen umsortieren; auf einen anderen Split verschieben (Mitte) oder an dessen linken/rechten Rand für einen neuen Split – der Tab behält seinen Zustand, Terminals laufen weiter |

## Explorer und Dateilisten

| Kürzel | Aktion |
|---|---|
| Leertaste | Schnellansicht (←/→ blättern, Enter öffnen, Leertaste/Esc schließen) |
| Enter | Öffnen (Ordner im Baum auf-/zuklappen) |
| Alt+Enter | Eigenschaften (Rechte, Besitzer, Gruppe) |
| F2 | Umbenennen |
| Entf | In den Papierkorb |
| Strg+C / Strg+X / Strg+V | Kopieren / Ausschneiden / Einfügen (kompatibel mit anderen Dateimanagern) |
| Alt+↑, Rücktaste | Übergeordneter Ordner (Dateiliste) |

## Texte, Code und Markdown

| Kürzel | Aktion |
|---|---|
| Strg+S | Sofort speichern (sonst automatisch nach 1 s) |
| Strg+F | Suchen im Dokument (Enter weiter, Umschalt+Enter zurück) |
| Strg+G | Gehe zu Zeile |
| Esc | Suche schließen |
| `[[` (Markdown) | Wiki-Link: Vorschläge aus dem Projekt, ↑/↓ wählen, Enter/Tab übernehmen |
| ⇠ / ◎ (Markdown, PDF) | Rückverweise mit Filtern / lokaler Graph |

## PDF

| Kürzel | Aktion |
|---|---|
| Strg+F | Volltextsuche im Dokument; F3 / Umschalt+F3 nächster / vorheriger Treffer |
| Bild↑ / Bild↓, Strg+Pos1 / Strg+Ende | Seiten blättern, Anfang / Ende |
| Strg++ / Strg+− / Strg+Mausrad | Zoom |
| Strg+0 | Seitenbreite |
| Ziehen / Doppelklick | Text auswählen (Wort); Umschalt+Klick erweitert die Auswahl |
| Strg+C | Ausgewählten Text kopieren |
| Strg+H | Auswahl markieren (zuletzt gewählte Farbe) |
| Strg+Q | Auswahl markieren und als Zitat in eine Notiz übernehmen |
| Strg+D | Lesezeichen für die aktuelle Seite setzen / entfernen |
| Klick / Rechtsklick auf eine Anmerkung | Kommentar, Farbe, Zitat, Link kopieren, Löschen |
| Strg+Enter (im Kommentar) | Kommentar übernehmen |
| Esc | Auswahl aufheben, zurück zum Auswahlwerkzeug |

## Kalender

| Kürzel | Aktion |
|---|---|
| T | Heute |
| Alt+← / Alt+→ | Vorige / nächste Woche bzw. Monat |
| Enter | Ausgewählten Eintrag bearbeiten |
| Entf | Ausgewählten Eintrag löschen |
| Klick / Doppelklick | Auswählen (Details rechts) / bearbeiten |
| Doppelklick auf freie Zeit, Ziehen über freie Zeit | Neuer Termin (eine Stunde / gezogener Zeitraum) |
| Eintrag ziehen, unteren Rand ziehen | Verschieben (15-Minuten-Raster) / Dauer ändern |
| Datei aus dem Explorer auf einen Eintrag / auf freie Zeit | Verknüpfen / Arbeitsblock anlegen |
| Datei auf „Noch nicht eingeplant“ | Als Aufgabe einplanen |
| Aufgabe in die Woche oder den Monat ziehen | Als Arbeitsblock einplanen |

## Terminal

| Kürzel | Aktion |
|---|---|
| Strg+Umschalt+C / Strg+Umschalt+V | Kopieren / Einfügen |
| Umschalt+Einfg | Einfügen |
| Rechtsklick | Menü: Kopieren, Einfügen, Ausgabe in Notiz übernehmen |
